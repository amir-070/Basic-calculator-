# Little Calculator

A simple, responsive calculator built for practicing core front-end development skills.

## Features

- Basic arithmetic: addition, subtraction, multiplication, and division
- Clear button to reset the calculation
- Delete button to remove the last input
- Responsive, easy-to-use calculator layout
- Handles decimal-number calculations

## Built With

- HTML
- CSS
- JavaScript

## Getting Started

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.

No installation is required.

## Project Structure

```text
little-calculator/
├── index.html
├── style.css
├── script.js
└── README.md
```

## Purpose

This project was created as a learning exercise to practice HTML structure, CSS styling, JavaScript event handling, and basic calculation logic.
